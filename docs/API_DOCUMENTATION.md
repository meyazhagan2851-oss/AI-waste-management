# API Documentation

Base URL (local development): `http://localhost:8000`

Interactive Swagger UI is auto-generated by FastAPI at **`/docs`**, and
ReDoc at **`/redoc`**, as soon as the backend is running.

---

## Health

### `GET /`
Basic welcome/health check.

**Response 200**
```json
{ "message": "AI Smart Waste Management System API is running.", "docs": "/docs", "status": "ok" }
```

### `GET /api/health`
Detailed health check, including whether a trained AI model or the
heuristic fallback is currently active.

**Response 200**
```json
{ "status": "healthy", "ai_model": "trained", "environment": "development" }
```

## Prediction

### `POST /api/predict`
Uploads a bin image, classifies it, and stores the result.

**Request:** `multipart/form-data`
| Field  | Type   | Required | Description                          |
|--------|--------|----------|---------------------------------------|
| file   | File   | Yes      | Image file (jpg, jpeg, png, webp)     |
| bin_id | String | No       | Bin identifier (default `BIN-001`)    |

**cURL example**
```bash
curl -X POST "http://localhost:8000/api/predict" \
  -F "file=@bin_photo.jpg" \
  -F "bin_id=BIN-007"
```

**Response 200**
```json
{
  "id": 42,
  "bin_id": "BIN-007",
  "image_name": "20260723101500_ab12cd34.jpg",
  "prediction": "Full",
  "confidence": 0.9421,
  "upload_time": "2026-07-23T10:15:00Z",
  "is_alert": true
}
```

**Errors**
- `400` — Unsupported file type
- `413` — File exceeds `MAX_UPLOAD_SIZE_MB`
- `500` — Internal prediction error

## History

### `GET /api/history`
Returns paginated, searchable, filterable prediction history.

**Query Parameters**
| Param      | Type   | Default | Description                                  |
|------------|--------|---------|------------------------------------------------|
| search     | string | ""      | Matches against image name or bin id           |
| prediction | string | ""      | Filter by exact class: Empty / Half Full / Full|
| bin_id     | string | ""      | Filter by specific bin                          |
| page       | int    | 1       | Page number (1-indexed)                         |
| page_size  | int    | 10      | Records per page (max 100)                      |

**Response 200**
```json
{
  "total": 132,
  "page": 1,
  "page_size": 10,
  "results": [
    {
      "id": 42,
      "bin_id": "BIN-007",
      "image_name": "20260723101500_ab12cd34.jpg",
      "prediction": "Full",
      "confidence": 0.9421,
      "upload_time": "2026-07-23T10:15:00Z"
    }
  ]
}
```

### `GET /api/history/image/{filename}`
Serves the stored image file for preview.

### `DELETE /api/history/{record_id}`
Deletes a single prediction record.

**Response 200**
```json
{ "message": "Record 42 deleted successfully" }
```

## Dashboard

### `GET /api/dashboard/stats`
Returns aggregate statistics for the dashboard summary cards & charts.

**Response 200**
```json
{
  "total_predictions": 132,
  "empty_count": 58,
  "half_full_count": 41,
  "full_count": 33,
  "full_bin_alert_count": 33,
  "average_confidence": 0.881,
  "last_updated": "2026-07-23T10:15:00Z"
}
```

### `GET /api/dashboard/bins`
Returns the latest known status of every distinct bin being tracked.

**Response 200**
```json
[
  {
    "bin_id": "BIN-007",
    "latest_prediction": "Full",
    "confidence": 0.9421,
    "last_checked": "2026-07-23T10:15:00Z",
    "is_alert": true
  }
]
```

## Notes

- All endpoints return standard HTTP status codes; error bodies follow
  FastAPI's default `{"detail": "..."}` shape.
- CORS is restricted to the origins listed in `ALLOWED_ORIGINS` (`.env`).
- Uploaded images are also served statically at `GET /uploads/<filename>`.
